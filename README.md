# Teaboom — карточка товара

Тестовое задание на позицию HTML-верстальщика / Frontend-верстальщика.

Реализована адаптивная карточка товара «Ананасовый улун» с выбором фасовки.

## Реализовано

- Семантическая HTML5-разметка.
- Адаптивная верстка для desktop, tablet и mobile.
- Выбор фасовки 100 г / 500 г / 1000 г / 5000 г.
- Динамическое обновление цены, старой цены и артикула.
- Активное состояние выбранной фасовки.
- Hover и active-состояния кнопки «В корзину».
- Демонстрационное состояние «Добавлено».
- Без подключения backend и реальной корзины.
- Дополнительно добавлено модальное окно с увеличенным изображением товара.

## Стек

- HTML5
- SCSS
- TS / JS
- Vite

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить dev-сервер:

```bash
npm run dev
```

Собрать prod-версию:

```bash
npm run build
```

Предпросмотр prod-сборки:

```bash
npm run preview
```
